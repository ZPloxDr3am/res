# Roteiro — Motoboy se cadastra pelo link (D-104)

1. Como dono, **Lojas e equipe → Equipe** → "🛵 Motoboys se cadastram sozinhos" → **Ver link e QR**. Aparecem o link, o QR, Copiar, Mandar no WhatsApp e Trocar link.
2. Abra o link numa janela anônima (ou no celular): "Entregas para <loja>". Envie sem marcar o aceite → pede o aceite. Usuário já existente → "Esse usuário já existe".
3. Envie certo → "✅ Cadastro enviado" com o botão para baixar o app.
4. No painel, a pessoa aparece "esperando aprovação" com WhatsApp (abre a conversa), veículo/placa e Pix. **Aprovar** → aparece na equipe como Motoboy; entre no app do motoboy com o usuário e a senha escolhidos.
5. Faça outro cadastro e **Recuse** → some da lista; o usuário escolhido fica livre de novo.
6. **Trocar link** → o link antigo mostra "Link inválido".
7. Plano no limite de aparelhos de motoboy → Aprovar mostra o aviso do plano.
