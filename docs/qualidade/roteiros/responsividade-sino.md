# Roteiro: responsividade e acessibilidade do painel (SINO)

Pré-condição: usuário dono ou gerente, com pelo menos uma loja que tenha pedidos, insumos e lançamentos. Use um celular de verdade (ou o modo de celular do navegador) e um notebook.

| # | Passo | Resultado esperado | Resultado |
|---|---|---|---|
| 1 | No celular (320 a 430 px), abrir cada item do menu "Mais" | Nenhuma tela anda para os lados com o dedo. A barra de baixo fica inteira, e um nome longo vira "…" | |
| 2 | Resumo no celular | Período, loja e datas cabem na tela. As datas ficam lado a lado e "Ver período" ocupa a largura toda. A linha "Indicadores… somam N lojas" diz de onde vêm os números | |
| 3 | Resumo com "Todas as lojas" e com uma loja só | A linha de escopo e a meta mostram "N lojas somadas" ou o nome da loja | |
| 4 | Pedidos no celular | Aparece a barra de status (Aguardando, Em preparo, Pronto…) com contagens. Tocar num status leva à coluna. Deslizar o quadro marca o status atual. A próxima coluna aparece pela borda | |
| 5 | Pedidos no celular: botão "loja em uso / Todas as lojas" | Os dois lados cabem na tela, sem cortar | |
| 6 | Filas que rolam de lado (filtros, abas, status) | A borda direita esmaece, indicando que há mais itens | |
| 7 | Novo pedido: combo de nome longo | O nome quebra em até duas linhas dentro do cartão | |
| 8 | Cardápio (notebook) | A busca fica no começo, sem vão acima da lista. O texto do cartão alinha à esquerda | |
| 9 | Estoque: "Um estoque do grupo" | O texto quebra dentro da opção | |
| 10 | Promoções | As cinco opções cabem numa linha no notebook. "Colocar produto em promoção" fica legível (texto claro sobre botão escuro) | |
| 11 | Relatórios | Números em cor neutra, sem emojis nos cartões. Cor só nos selos bom/atenção/demorado | |
| 12 | Clientes | Nome, telefone e segmento alinhados à esquerda | |
| 13 | Fidelidade: "Usar no máximo" | O texto "sem limite" aparece inteiro | |
| 14 | Aplicativos | Títulos em cor de texto (não em tomate). Selos: Ligado/Incluso em verde, Disponível em azul, Em breve neutro | |
| 15 | Impressoras | Diz "Programa de impressão". A tabela cabe no notebook e vira lista no celular | |
| 16 | Delivery, fora do horário | A vitrine e o bloco do link mostram os dois "Fechado agora" | |
| 17 | Teclado: Tab pelas telas | Todo item focado ganha um contorno visível | |
| 18 | Tema escuro nas mesmas telas | Selos, mesas do Salão e botões legíveis | |

Observações: o programa instalado no computador da impressora ainda se chama "RES Impressão" até sair uma versão nova.
