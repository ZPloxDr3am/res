# Roteiro: tema claro, escuro ou automático (D-112)

Pré-condição: qualquer usuário logado no painel; um computador e um celular (ou o app RES).

| # | Passo | Resultado esperado | Resultado |
|---|---|---|---|
| 1 | Computador: no rodapé do menu, clique em **Tema: Automático** | Abre "Aparência" com Claro · Escuro · Automático; Automático marcado | |
| 2 | Clique em **Escuro** | O painel inteiro fica escuro na hora, sem recarregar; o rodapé mostra "Tema: Escuro" | |
| 3 | Recarregue a página (F5) e abra outra tela (Pedidos, Resumo) | Continua escuro e **não pisca branco** ao carregar | |
| 4 | Abra o painel em outra aba | Já abre escuro; trocar numa aba troca na outra | |
| 5 | Escolha **Claro** com o Windows/macOS em modo escuro | O painel fica claro mesmo com o sistema escuro | |
| 6 | Escolha **Automático** e troque o modo do sistema (claro ↔ escuro) com o painel aberto | O painel acompanha sozinho | |
| 7 | Celular: **Mais → Aparência** | Mesmas três opções; a escolha do celular não muda a do computador | |
| 8 | Quadro de pedidos, selos (Delivery, atrasado), relatórios e Financeiro no escuro | Textos e selos legíveis | |
| 9 | Abra o cardápio digital (`/c/<marca>`) num aparelho que nunca abriu o painel | Segue o modo do aparelho | |
