# Documentação do RES

Tudo do projeto fica neste repositório, em três áreas. Comece pela que é sua.

| Área | Para quem | O que tem |
|---|---|---|
| [**Comercial**](comercial/README.md) | Vendas, apresentação a clientes, suporte | O que o RES faz, por módulo, em linguagem de cliente; novidades de cada semana; comparação com o BeeFood |
| [**Desenvolvimento**](desenvolvimento/README.md) | Quem constrói (pessoas e o Claude de cada um) | **Método de trabalho**, como começar, donos de cada módulo, roteiro do que vem, decisões (D-001…) |
| [**Qualidade / testes**](qualidade/README.md) | Quem testa e valida | Como testar, roteiros por módulo, relatórios de cada rodada de testes |

Tarefas, bugs e pedidos de teste ficam nas **Issues** do GitHub (com modelos prontos); o andamento da semana fica no **marco (milestone)** da semana.
